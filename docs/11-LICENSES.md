# 11 — 版权 / 许可 / AI 生成声明

`最后更新: 2026-09-30(轮 48)` 商店页与发布包的"法务清单":谁的东西、什么许可、哪些是 AI 生成。

## 1. 本仓库产出(自有)
| 内容 | 说明 | 许可 |
|---|---|---|
| 游戏代码(web/ + unity/) | 本项目原创(人机结对编写) | 保留所有权利(发布前可改 MIT,决策点见 10 §决策②) |
| 游戏设计/文案/数值 | 本项目原创 | 同上 |

## 2. AI 生成内容(需在商店页声明)
| 内容 | 生成方式 | 后处理 |
|---|---|---|
| 全部像素立绘/动画帧/图标/特效贴图(web/public/sprites/) | 文生图 + 图生图(提示词与批次记录:docs/08) | 品红键出/统一缩放/64 色板量化(tools/process_art.py) |
| 音效/环境声 | 程序化合成(WebAudio,engine/audio/) | 非采样,无第三方素材 |
| 位图字体 | 程序化点阵(非第三方字体文件) | — |

**商店页声明模板**:"本游戏的美术素材由 AI 辅助生成并经人工筛选与像素化处理;代码由人机结对编写。"

## 3. 第三方依赖(仅构建期,不进发布包)
| 依赖 | 用途 | 许可 |
|---|---|---|
| Vite / Vitest / TypeScript | 构建与测试 | MIT |
| .NET 8 SDK | C# 逻辑层测试 | MIT |

发布包(dist)为纯静态产物,不包含任何第三方运行时代码(零 runtime 依赖是架构决策,见 docs/02)。

## 4. 不可用素材黑名单
- 任何来源不明的图片/音频/字体一律不进仓库;
- AI 生成时提示词不得包含在世艺术家名/商标/IP 角色名(批次记录可审计,见 docs/08)。
