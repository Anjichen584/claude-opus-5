## Phase 0 — 文档与骨架 ✅(本次)
- 全套设计/架构/数值/美术/协作文档(docs/ 8 篇)
- web/ 工程骨架(可 `npm run dev` 跑通空场景)+ unity/ 目录骨架
- **验收**: 新人只读 docs 能完整复述项目设计与现状

## Phase 1 — 引擎核心 + 可动小人(预估 ~6k 行)
- ECS(World/Query/事件)、固定步长主循环、渲染分层、输入动作映射
- 空间哈希碰撞、相机跟随、对象池、可播种 RNG
- 剑士色块占位小人: 移动/翻滚(无敌帧)/三段普攻打木桩,顿帧+屏震+飘字全套打击感
- 工具链: quantize.ts / pack-atlas.ts;首批美术: 剑士全动作 + 场景 tile
- **验收**: 浏览器里砍木桩"手感对了"(对照 GDD §3.1 逐条检查)

## Phase 2 — 战斗纵深(预估 ~8k 行)
- 伤害管线全量(词条聚合/暴击/减免)、Buff/DoT、元素印记+6 种连锁反应
- 技能系统(数据驱动 phases)+ 剑士 Q/E/R、符文修饰器 + 首批 9 个符文
- 第一章 5 种怪 AI(行为树)+ 美术、音频系统 + 首批音效
- **验收**: 一个房间内割 30 只怪,连锁反应正确、无帧率跌落

## Phase 3 — 刷宝循环(预估 ~7k 行)
- 装备6部位/5稀有度/词条滚动/掉落表/保底、背包+装备对比 UI、药剂
- 房间模板×12、程序化连接、选路 UI、商店/事件/宝箱房
- 昼夜循环 + 怪潮变异 + 星灯决策
- **验收**: 完整推图 20 分钟循环成立,"再来一局"欲望自评 ≥ 7/10

## Phase 4 — Boss 与局外成长(预估 ~5k 行)
- Boss 南弥尔三阶段状态机 + 美术 + 战斗演出、结算页
- 星陨祭坛成长树、图纸系统、存档+版本迁移
- **验收**: 第一章从标题画面到通关结算全流程无断点 = 垂直切片完成 🏁

## Phase 5 — 打磨与扩展 🔶 进行中

- ✅ GitHub Pages 自动部署(CI 双 job:逻辑测试 + 构建部署)
- ✅ 位图字体 / 9-slice 面板 / 9 种房间布局模板 / 地形机制(浅滩·可打穿障碍)
- ☐ 剩余:UI 图标与动画序列、技能特效贴图、难度层、新手引导、性能与图集
- ☐ **工作量见 [09-SCOPE.md](09-SCOPE.md)(口径 B ≈ 30–42 轮);执行计划见 [10-FULL-PLAN.md](10-FULL-PLAN.md)(v1.0 = 52 轮 + 8 轮机动)**
