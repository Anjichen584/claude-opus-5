## 文档维护规则

1. **06-STATUS.md 每次有实质提交后必须更新**(完成项打勾、写明日期与 commit)。
2. 每篇文档头部有 `最后更新` 字段,改动时同步更新。
3. 玩法改动 → 改 01/03;代码结构改动 → 改 02;新增资源 → 改 04 的资源清单 + 08 的提示词存档。
4. 提交信息规范见 07-CONTRIBUTING.md,文档提交用 `docs:` 前缀。
