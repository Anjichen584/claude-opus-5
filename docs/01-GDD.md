## 1. 概述

| 项 | 内容 |
|---|---|
| 名称 | 星陨骑士 · 序章 (Starfall Knights: Prelude) |
| 类型 | 俯视角像素刷宝割草 ARPG(打怪→掉装→Build→更强的怪) |
| 视角 | 2D 俯视 3/4 视角 |
| 平台 | 浏览器(键鼠 + 手柄计划中),Unity 副线可出移动端 |
| 单局时长 | 一章 15~25 分钟,局外成长永久保留 |
| 参考品类 | 割草刷宝 ARPG 品类通用机制(仅机制层面,内容全原创) |

### 1.1 三大差异化支柱(我们的独有优势)

1. **元素连锁反应** — 火/冰/雷/毒四系印记两两组合产生 6 种反应,鼓励技能搭配而非单一堆伤害。
2. **符文改装** — 每个技能有 3 个符文槽,符文彻底改变技能形态(不是加数值,是改行为)。
3. **昼夜怪潮** — 局内实时昼夜循环,夜晚怪物变异+掉落翻倍,玩家主动选择"风险换收益"。

### 1.2 核心循环

```
选职业 → 进入章节 → 清房间(割草) → 拾取装备/符文 → 房间选路(分支)
   ↑                                                        ↓
局外成长(星陨祭坛) ← 结算(货币/图纸) ← Boss 战 ← 夜晚怪潮(可选)
```

## 2. 世界观(全原创)

**大陆**: 艾露维亚 (Eluvia) — 千年前"星陨之夜"坠落的星核碎片赋予大陆魔力,
也孵化出被星核辐射扭曲的"蚀兽"。

**主线冲突**: 蚀渊教团首领 **卡尔冢 (Karzhum)** 试图挖出深埋地底的主星核,
让全大陆生物"蚀化"。玩家是新组建的**星陨骑士团**首批成员,沿星核碎片坠落带推进,
封印各地的碎片裂隙,最终阻止卡尔冢。

**基调**: 明快冒险+轻幽默,NPC 对白短小俏皮,不走黑暗致郁路线。

**章节地理**(对应推图章节):
1. 翠语林地(垂直切片章节)→ 2. 灰烬矿脊 → 3. 沉星湖窟 → 4. 蚀渊王座(最终章)

## 3. 操作与手感(手感是生命线,优先级最高)

| 输入 | 键鼠 | 说明 |
|---|---|---|
| 移动 | WASD | 8 方向,加速度 0.08s 到满速,松键 0.05s 停 |
| 普攻 | 鼠标左键 | 朝鼠标方向,可按住连发,三段连击(见 3.1) |
| 技能 1/2/3 | Q / E / R | R 为大招,充能型 |
| 翻滚 | 空格 | 0.35s 无敌帧,冷却 1.2s,可取消普攻后摇 |
| 交互/拾取 | F | 拾取有 0.8m 磁吸,货币全自动吸取 |
| 药剂 | 1 | 恢复 40% HP,每房间充能 |

### 3.1 打击感规范(实现必须逐条对齐)

- **连击**: 普攻三段,第三段伤害 x1.6 并带 0.3m 击退;连段窗口 0.6s。
- **顿帧 (hitstop)**: 命中普通怪 40ms,暴击 70ms,击杀 90ms。
- **屏震**: 暴击 2px/80ms,大招命中 5px/150ms,Boss 技能 8px/250ms。
- **受击反馈**: 怪物受击闪白 2 帧 + 后仰 4px + 飘字(白普通/黄暴击/元素色反应)。
- **尸体与残留**: 击杀有溶解粒子,地面留焦痕/冰渣等元素痕迹 3s。
- **音频**: 命中音随连段升调;割草连杀 10+ 触发混响加强。

## 5. 技能符文系统(差异化支柱 ②)

每个技能 3 个符文槽(等级 5/15/25 解锁)。符文是掉落物,分职业通用/技能专属两类。

**示例 — 剑士 Q「裂空斩」的专属符文**(展示"改形态"原则):

| 符文 | 效果(彻底改变行为) |
|---|---|
| 焚风之种 | 斩击附火印记,扇形范围留下 2s 火焰地带 |
| 回音裂隙 | 三连斩变两段,但每段发射一道穿透剑气飞行 6m |
| 引力斩核 | 末段拉怪范围 x3,但冷却 +40%(配大招组合技) |

**通用符文示例**: 冷却回响(击杀 -0.3s 冷却)、印记延续(元素印记时长 +50%)。

**设计规则**: 符文必须"改变玩法决策",纯数值加成一律做进装备词条,不做符文。

## 6. 元素连锁系统(差异化支柱 ①)

四系印记: 🔥火 / ❄冰 / ⚡雷 / ☠毒。攻击带元素则给怪挂印记(4s),
**不同元素**第二次命中时触发反应并清除印记:

| 组合 | 反应 | 效果 |
|---|---|---|
| 火+冰 | 蒸爆 | 范围 AOE,伤害 =(触发攻击的 180%) |
| 火+雷 | 超载 | 单体大额伤害 + 击退 2m |
| 火+毒 | 燃瘴 | 生成 3m 毒火云,持续 3s 每 0.5s 跳伤 |
| 冰+雷 | 冻链 | 电弧弹射至 4 个目标并减速 40% |
| 冰+毒 | 脆蚀 | 目标受到伤害 +25%,持续 4s(debuff) |
| 雷+毒 | 麻痹 | 眩晕 1.2s(Boss 改为减抗) |

**割草爽点设计**: 反应可以连锁传染——蒸爆的 AOE 如果命中带印记的其他怪,继续触发反应,
形成"一炮引爆全场"的多米诺时刻(每次连锁伤害衰减 20%,防数值爆炸)。

## 9. 关卡结构与昼夜怪潮(差异化支柱 ③)

**章节结构**: 12~15 个手工模板房间,程序化连接(战斗 60% / 精英 15% / 事件 10% / 商店 10% / 宝箱 5%),
每 3 个房间后出现双岔路选择(显示下个房间类型图标),Boss 房固定在末尾。

**昼夜循环**: 局内 1 昼夜 = 6 分钟(昼 4 / 夜 2)。夜晚:
- 视野半径收缩 30%,怪物获得变异词缀(狂暴/分裂/蚀化光环 随机一种);
- 掉落数量 x2,稀有度权重上移一档;
- 房间入口可选择"点燃星灯"跳过夜晚(用货币买安全,核心风险决策点)。

## §9.1 每日挑战(混沌祭坛) · 2026-09-29 实装

- **入口**:星陨营地南侧「🗓 混沌祭坛」。
- **规则**:按本地日期取 seed(全服同种子),抽 **3 条风险收益词条**;章节固定第一章,保证可比。
- **词条设计铁律**:**每条都必须有得有失**(纯增益会让某天白给,纯惩罚会让某天没人玩),由单测守卫。
  现有池:兽潮 / 铁壁 / 狂怒 / 贪星 / 迅影 / 薄甲 / 巨力 / 长夜 / 节制 / 战地医师。
- **生效方式**:敌人生命·攻击乘区、掉落乘区、玩家攻击·生命乘区、冷却缩短追加(上限 40%→60%)、
  初始药剂增减、昼夜周期乘区。全部走 `dungeon/RunMods` 单例,系统侧只读乘区,普通局 = 全中性。
- **记录**:仅保留当日最佳(通关/最快/击杀),跨天自动作废 —— 不追求长线排行,只做"今天来一把"的日常理由。

## §9.2 房间布局模板(障碍物摆放) · 2026-09-29 实装

**动机**:垂直切片里每间房都是同一块空地 + 纯随机撒点,玩家记不住房间、怪也没地形可绕。现在分"模板摆位"
与"统一过规则"两步走(`web/src/game/dungeon/RoomLayouts.ts`)。

**模板(9 种)**:林间散布 / 石柱阵 / 密林 / 林荫走廊 / **窄道** / **环形擂台** / **溪畔浅滩** / Boss 场 / 静谧房间。
战斗房按权重抽(散布 20 / 石柱 16 / 走廊 16 / 密林 14 / 窄道 14 / 环形 12 / 浅滩 10),精英房只在有地形的四种里抽,
商店·宝藏·秘境固定静谧房间,Boss 房固定 Boss 场。

| 模板 | 地形意图 | 玩家能玩到什么 |
|---|---|---|
| 林间散布 | 稀疏树石 | 基础割草手感,不干扰走位 |
| 石柱阵 | 2×3 岩柱 | 挡枪线、绕背打傀儡 |
| 密林 | 四角成丛、中场开阔 | 风筝流的主场 |
| 林荫走廊 | 上下两排树夹土路 | 引导纵向走位,横向被树挤压 |
| 窄道 | 两道岩墙 + 两个错开门洞 | 通道被压到 5m,只能正面接敌;外侧口袋可绕 |
| 环形擂台 | 外圈树石环、中央空场 | 中央无遮挡 1v1,三处缺口进出 |
| 溪畔浅滩 | 一条横穿房间的水带 | 趟水过场,两岸芦苇(无碰撞)只挡视线 |

**摆放规则(数值全走 `balance.json` 的 `layouts` 段)**:
- **入口净空** 4.6m:玩家落点在 2.5m,免得一进门卡在树上;
- **出口净空** 4.6m:传送门在 W-2,±2.5m 两个;
- **交互净空** 1.6m:摊位/石碑/宝箱周围不立树石(商品不再被树挡死);
- **可穿行** 散件间距 ≥ 1.6m:必须大于"岩 0.4 + 玩家 0.32"的直径 1.44m,否则随机点会意外连成墙;
- **墙是故意砌的**:窄道墙砖间距 0.7m(< 1.44m ⇒ 钻不过去),但门洞与通道净宽 ≥ 3.2m 由模板保证。

**可测性**:`auditLayout()` 逐条查规则违规(越界/净空/间距/水里立树/模板个性),单测对 9 模板 × 5 种子断言零违规;
模板规则与 C# 镜像的常量由 `ParityTests` 逐键比对。

**现状边界**:浅滩/窄道目前只是地形与观感(水不减速、墙不可破),机制化排在下一步。

## §9.3 周常挑战(混沌祭坛 · 周页签) · 2026-09-29 实装

**动机**:每日挑战只解决"今天来一把";长线需要"这一周都有的目标"。周常不是把每日的乘区再调大,而是
**改本局的规则**:一周内随时可打、成绩可比,跨周自动作废。

- **键与种子**:ISO 周键 `2026-W40`(周一为一周之始、归属看周四 → 1 月 1 日可能属于上一年最后一周);
  复用每日那套 FNV-1a + 雪崩散列(相邻周 seed 必须不相关,否则会连着两周抽到同一条铁律)。
- **组成**:1 条**铁律** + 2 条每日池词条(3 条,与每日挑战同量级)。抽签顺序固定:先铁律 → 再词条(剔除同 id) → 再地形。
- **铁律池(8 条,全部"有得有失",由单测守卫)**:铁闸(每房 +1 波、掉落 ×1.3)/ 闭市(商店房不再出现、掉落 ×1.45)/
  封坛(祭坛永久成长失效、敌人生命 -20%)/ 先手(精英房提前 2 间、掉落 ×1.25)/
  地脉(战斗房地形被定死为窄道·环形·浅滩之一、敌人生命 -15%)/ 薄壳(生命 -40%、攻击 +40%)/
  永夜(昼夜加速 ×0.5、掉落 ×1.4)/ 背水(生命 -30%、掉落 ×1.5、冷却 -20%)。
- **结构性改动**走 `RunMods.structure`,系统侧只读(不需要 `if (isWeekly)`):额外波数、商店关门、祭坛失效、
  精英位偏移、强制地形(与房间布局模板共用同一套模板表)。
- **入口**:营地「🗓 混沌祭坛」双页签(`[Tab]` 今日 / 本周);本周页显示铁律卡、结构摘要与本周记录。
- **记录**:`meta.data.weekly`(通关 / 最佳时间 / 击杀)+ `stats.weeklyClears` 累计;成就「🏅 铁律破译者」。
